### FB-0116 — A slash-command argument is substituted, not passed — so it must leave the shell block entirely

**Date:** 2026-09-26
**Source:** user dispatch of the `$ARGUMENTS` render-time-injection fix, plus the measured refutation of the brief's own site classification

**What was said:** the orchestrator dispatched this as the routing table's one-way-door/architecture row, stating the constraint precisely: *"No delimiter, quoting, or in-block guard can work, because substitution precedes parsing — a quoted-delimiter heredoc was tried and defeated by a payload whose second line equals the delimiter, and the guard then printed a clean-looking refusal after the command had run. The argument must leave the block."* And on being shown that the brief's own exclusion of `review-brief:69` rested on an inferred mechanism: *"That premise was mine and it was wrong. I classified block types and then inferred that substitution skips fenced blocks; I never measured it. Excluding a known hole on a false premise is worse than the hole."*

**Synthesized rule:**

1. **`$ARGUMENTS` is not a parameter, it is a macro.** The host does a flat `replaceAll` over the **entire** skill body — prose, fenced blocks and `` !` `` spans alike — with an escaper that neutralises bang-command syntax and performs **no shell escaping**. Claude Code documents this against itself, in the refusal it prints for a Gemini import: *"Claude Code's `$ARGUMENTS` substitution doesn't [shell-escape], so importing would let typed arguments inject shell commands."* Consequences that are not obvious from the name: quoting is not protection (`"$ARGUMENTS"` still admits `$(…)`, a backtick and a closing quote — though it *does* contain `;` and newlines, which is what makes a partial mitigation look total); a `` !` `` block executes at **render time**, so no permission prompt stands between the payload and the shell; and **`$0`–`$9` are the same mechanism**, which makes every shell positional and awk field reference in a skill body a placeholder.
2. **The only fix is the argument leaving shell source; everything else is narrowing.** Heredocs, sentinels and fences all fail identically because every text boundary can appear in the text (FB-0108 rule 2). Two channels work, chosen by the agent's tool grant, not by taste: **Tier 1** — the agent uses its own `Read`, because a `context: fork` reviewer has no `Bash` and a render-time block therefore cannot be handed the value by anyone; **Tier 2** — the model writes the value with `Write` and the block reads a **fixed literal** path (FB-0108's `--finding-file` channel). A `--…-from PATH` flag must **refuse** a multi-line value rather than take line 1: a path has no second line, so truncating hides the attempt.
3. **Classify by measurement, never by inference — and this applies to the exclusion list, not just the fix.** The dispatch brief classified `review-brief:69` as "not exposed" because it sits in a fenced block. Reading the host's substitution routine showed the replace is over the whole body, so the value *does* arrive; the fence changes only *who* executes it. An inferred mechanism lost to a measured one for the fourth time in this program. Corollary: a site list you were handed is a hypothesis. Re-derive it, and re-derive it again at rebase.
4. **Write the rule down where it is cited, once.** The predicate lives in `plugins/flow/lib/arg_placeholders.py` with the host's regexes transcribed, and the prose in `docs/workflow.md` § "Skill arguments: the prose rule". Four skills cite that section by name, and an eval asserts the citation resolves — a named doc anchor referenced from code is a contract with a document (FB-0010 item 2).

5. **A detector for a host behaviour must be tabulated against that behaviour in both directions, not spot-checked.** The escape rule here is genuinely counter-intuitive and the obvious reading is wrong: the host's arm is `(?<!\\)\\\$`, so it consumes `\$` only when that backslash is not itself preceded by one — which means **two** backslashes leave the placeholder LIVE. A naive `(?<!\\)` lookbehind (the first thing anyone writes, and what shipped in this PR's first draft) silently passes every run of 2+ backslashes, certifying a working injection site as clean. The defence is a table of every form the host recognises, asserted **both** ways — a miss is a certified hole, and an over-match is noise that trains authors off the spelling you want them on. And when two artifacts model the same boundary (here a matcher and a render emulation), assert they agree row by row: FB-0109's two-definitions-of-one-boundary class applies to a detector and its own emulation just as much as to a reader and a writer.
